# PolyGame

Демо гібридної казуальної гри: п'ять хітів в одному циклі. Один файл `index.html`, без збірки та залежностей.

**Грати: https://zimavlad.github.io/PolyGame/** (GitHub Pages з цієї гілки). На телефоні можна додати на домашній екран: гра відкриється на весь екран, як застосунок.

## Що звідки

| Гра | Що взято | Як працює в PolyGame |
| --- | --- | --- |
| Block Blast | Фігури в лотку на 3 штуки, перетягування, кінець гри, коли нічого не влазить | Основний хід гравця |
| Sudoku | Поле 9×9 з квадратами 3×3 | Очищається повний рядок, стовпець **або** квадрат 3×3 |
| Two Dots | Клітинки-точки, ланцюжок з сусідніх точок одного кольору, петля | Ланцюжок лопає точки за 1 ⚡; петля прибирає весь колір з поля |
| Don't Touch the Spikes (Ketchapp) | Пташка між стінами з шипами, тап = змах | Аркадний раунд **Spike Rush**: цукерки дають ⚡ |
| Stack (Ketchapp) | Блок їздить, тап = скинути, зайве відрізається | Аркадний раунд **Stack**: ідеальне попадання дає ⚡ |

## Ігровий цикл

1. Головоломка: ставиш фігури, очищаєш лінії й квадрати. Кожне очищення дає +1 ⚡ і заповнює шкалу **РАШ**.
2. Повна шкала відкриває аркадний раунд. Раунди чергуються: Spike Rush, потім Stack.
3. Енергія ⚡ з аркади повертається в головоломку як інструмент порятунку: ланцюжки й петлі Two Dots звільняють місце, коли фігури вже не влазять.

Одна валюта (⚡) зшиває обидва режими: навичка в аркаді прямо впливає на виживання в головоломці.

## Бонуси

- **Комбо**: очищення кілька ходів підряд множить очки (до ×6).
- **МОНО**: очищена лінія чи квадрат одного кольору дає +90 очок і +1 ⚡.
- **Петля**: замкнений ланцюжок прибирає з поля всі точки цього кольору.
- Чим заповненіше поле, тим більше шипів у Spike Rush.

## Відчуття на телефоні

- Мʼяка вібрація на кожну дію: короткий тік на крок ланцюжка, подвійний на очищення, «успіх» на комбо й петлю. На Android працює через вібромотор, на iPhone (iOS 18+) через системний тактильний відгук. Вимикається іконкою телефона вгорі.
- Звуки м'які: синтезовані тони через фільтр, без різких хвиль. Вимикаються іконкою динаміка.
- Фігура при перетягуванні піднімається над пальцем на свою висоту, тож її видно повністю. Якщо не влазить, плавно повертається в лоток.
- Рядки, які очистяться, заздалегідь підсвічуються кольором фігури.

## Керування

- Миша або палець: перетягнути фігуру з лотка; провести по точках на полі.
- В аркаді: тап / клік / пробіл.
- Для демо: клавіші `1` та `2` одразу запускають Spike Rush і Stack.

## Логи гри

Гра пише детальний журнал і надсилає його на наш збирач (`server/`). Він записує:

- запуск: пристрій, екран, iOS чи Android, чи відкрито як застосунок з домашнього екрана, чи є вібромотор, збірка;
- кожен хід: фігура, клітинка, скільки тривало перетягування, заповненість поля, скільки ліній очистилось;
- фігури, що повернулися в лоток, ланцюжки й петлі, спроби без енергії, попередження «не влазить»;
- аркаду: Spike Rush (відбиття, цукерки, від чого загинула пташка, скільки тапів), Stack (поверхи, ідеальні попадання, наскільки промахнувся останній блок);
- кінець партії: рахунок, тривалість, лінії, петлі, енергія, заповненість поля;
- частоту кадрів кожні 30 с, помилки JavaScript, згортання застосунку, перемикачі звуку й вібро, самооновлення.

Без мережі події чекають у черзі на телефоні й досилаються пізніше. Коли застосунок згортають, решта йде через `sendBeacon`. Гра нікого не ідентифікує: тільки випадковий id пристрою, IP на сервері зберігається лише як солений хеш.

### Збирач

`server/collector.mjs`: Node 22 без залежностей. Запускається в Docker (`server/Dockerfile`, `server/docker-compose.yml` з томом для логів).

| Запит | Що робить |
| --- | --- |
| `POST /e` | приймає пачку подій від гри |
| `GET /health` | перевірка, що збирач живий |
| `GET /days` | список днів (потрібен `Authorization: Bearer READ_TOKEN`) |
| `GET /logs?day=YYYY-MM-DD` | сирі логи за день, JSON Lines (потрібен той самий ключ) |

Деплой у Coolify: New Resource → Public Repository → цей репозиторій і гілка → Build Pack: Docker Compose, Base Directory `/server` → домен `https://polygame-logs.91.99.8.73.sslip.io` для сервісу `collector` на порт 8080 → змінні `READ_TOKEN` (довгий випадковий рядок) та `IP_SALT`.

### Аналіз

```
curl -sH "Authorization: Bearer $POLYGAME_LOG_TOKEN" "https://polygame-logs.91.99.8.73.sslip.io/logs?day=2026-10-09" | node server/analyze.mjs
```

Звіт: пристрої, партії, рахунки, частка фігур, що не стали на поле, смерті в Spike Rush за причинами, вежі в Stack, FPS, помилки.
