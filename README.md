# PolyGame

Гібридна казуальна гра: головоломка Block Blast × Sudoku × Two Dots, аркади в стилі Ketchapp і класичні міні-ігри у вигляді «реклами». Статичний сайт без збірки й залежностей.

**Грати: https://zimavlad.github.io/PolyGame/** (GitHub Pages з цієї гілки). На телефоні можна додати на домашній екран: гра відкриється на весь екран, як застосунок, і сама оновлюватиметься.

## Режими

- **Шлях.** Карта рівнів. Кожен рівень має завдання й ліміт ходів: очистити лінії чи квадрати, зібрати точки певного кольору, замкнути петлю, набрати очки. За рівень 1–3 зірки. Кожен третій вузол — аркадний рівень. Програв, тоді «+5 ходів за міні-гру».
- **Нескінченна гра.** Класичний режим на рекорд: очищення заповнюють шкалу РАШ, а повна шкала запускає наступну аркаду з ротації.
- **Ігротека.** Усі аркади й міні-ігри окремо. Аркади пам'ятають свій рівень складності.

## Що звідки

| Гра | Як працює в PolyGame |
| --- | --- |
| Block Blast | Лоток на 3 фігури, перетягування на поле 9×9, кінець, коли нічого не влазить |
| Sudoku | Поле поділене на квадрати 3×3. У судоку-рівнях на точках цифри 1–9, і діє правило судоку: цифра не може повторюватися в рядку, стовпці й квадраті. Фігура з конфліктною цифрою не ставиться, конфлікт підсвічується червоним. Повний рядок чи квадрат там — розв'язаний шматок судоку (×2 очок) |
| Two Dots | Точки одного кольору поруч можна з'єднати пальцем і лопнути за 1 ⚡; петля прибирає весь колір |
| Ketchapp | Аркади Spike Rush (Don't Touch the Spikes), Stack, Knife Hit, ZigZag |
| Класика | Аркади Color Switch, Flappy, Timberman; міні-ігри Pop It, Pull the Pin, Water Sort, Мемо, Кріт, Судоку 4×4 |

## Аркади з прогресом

Кожна аркада має свої рівні. Перший легкий (повільно, широкі проходи, коротка ціль), кожна перемога відкриває наступний, трохи складніший. Усередині раунду складність теж наростає поступово. Перемога дає +100 очок і +1 ⚡.

## «Реклама»

Пародія на ігрові рекламні банери: міні-гра в рамці «РЕКЛАМА» з гучним заголовком на кшталт «99% не пройдуть». Закрити можна через 15 секунд. Пройдеш, тоді отримаєш нагороду. З'являється між аркадами в нескінченному режимі (не частіше ніж раз на 2,5 хвилини), після кожного другого рівня Шляху і як «+5 ходів», коли рівень програно.

## Енергія ⚡

Одна валюта зшиває все: її дають очищення, МОНО-лінії, аркади й міні-ігри, а витрачаєш її на ланцюжки й петлі, які рятують заповнене поле.

## Відчуття на телефоні

- Мʼяка вібрація: тік на крок ланцюжка, подвійний на очищення, «успіх» на комбо й петлю. На Android через вібромотор, на iPhone (iOS 18+) через системний тактильний відгук. Вимикається іконкою телефона вгорі.
- М'які синтезовані звуки через фільтр. Вимикаються іконкою динаміка.
- Фігура при перетягуванні піднімається над пальцем; якщо не влазить, плавно повертається в лоток. Рядки, що очистяться, підсвічуються заздалегідь.

## Як влаштовано

| Файл | Що в ньому |
| --- | --- |
| `index.html` | оболонка, стилі, екрани меню, карти, ігротеки, підсумку рівня |
| `js/core.js` | рушій, головоломка, хост аркад і хост «реклами», HUD, логи, самооновлення |
| `js/levels.js` | рівні Шляху, карта, ігротека, меню |
| `js/games/*.js` | аркади, кожна окремим модулем |
| `js/minis/*.js` | міні-ігри для «реклами» |
| `docs/MODULES.md` | контракт модуля: як додати нову аркаду чи міні-гру |
| `server/` | збирач логів і скрипт аналізу |

Для розробки: `index.html?arcade=knife&level=3`, `?ad=pin`, `?lvl=6`, `?endless` відкривають гру одразу; `nolog` вимикає відправку логів. У нескінченному режимі клавіші `1`–`9` запускають аркади, `0` — «рекламу».

## Логи гри

Гра пише детальний журнал і надсилає його на наш збирач (`server/`). Він записує:

- запуск: пристрій, екран, iOS чи Android, чи відкрито як застосунок з домашнього екрана, чи є вібромотор, збірка;
- кожен хід: фігура, клітинка, скільки тривало перетягування, заповненість поля, скільки ліній очистилось;
- фігури, що повернулися в лоток, ланцюжки й петлі, спроби без енергії, попередження «не влазить»;
- аркаду: Spike Rush (відбиття, цукерки, від чого загинула пташка, скільки тапів), Stack (поверхи, ідеальні попадання, наскільки промахнувся останній блок);
- кінець партії: рахунок, тривалість, лінії, петлі, енергія, заповненість поля;
- частоту кадрів кожні 30 с, помилки JavaScript, згортання застосунку, перемикачі звуку й вібро, самооновлення.

Без мережі події чекають у черзі на телефоні й досилаються пізніше. Коли застосунок згортають, решта йде через `sendBeacon`. Гра нікого не ідентифікує: тільки випадковий id пристрою, IP на сервері зберігається лише як солений хеш.

### Збирач

`server/collector.mjs`: Node 22 без залежностей. Запускається в Docker (`server/Dockerfile`, `server/docker-compose.yml` з томом для логів).

| Запит | Що робить |
| --- | --- |
| `POST /e` | приймає пачку подій від гри |
| `GET /health` | перевірка, що збирач живий |
| `GET /days` | список днів (потрібен `Authorization: Bearer READ_TOKEN`) |
| `GET /logs?day=YYYY-MM-DD` | сирі логи за день, JSON Lines (потрібен той самий ключ) |

Деплой у Coolify: New Resource → Public Repository → цей репозиторій і гілка → Build Pack: Docker Compose, Base Directory `/server` → домен `https://polygame-logs.91.99.8.73.sslip.io` для сервісу `collector` на порт 8080 → змінні `READ_TOKEN` (довгий випадковий рядок) та `IP_SALT`.

### Аналіз

```
curl -sH "Authorization: Bearer $POLYGAME_LOG_TOKEN" "https://polygame-logs.91.99.8.73.sslip.io/logs?day=2026-10-09" | node server/analyze.mjs
```

Звіт: пристрої, партії, рахунки, частка фігур, що не стали на поле, смерті в Spike Rush за причинами, вежі в Stack, FPS, помилки.
